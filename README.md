# ArtemisInRealTime

Run `npm run dev` to open the local site on port 8000.

The `/mission-events-test` prototype visualizes the mission history with flight-day
navigation, category lanes, event clusters, filters and an event detail panel. It
loads the complete `artemis-ii/web/timeline.json` produced by batch stage 1h once;
day navigation and filtering use the in-memory data.
